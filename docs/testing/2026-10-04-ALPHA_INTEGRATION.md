# 2026-10-04 alpha 沙盒接入验证

环境：独立 alpha 槽位，npm DSH 0.2.1-alpha.1，Node 24.12.0。安装 next-ver 构建快照；未操作全局 DSH，未调用真实模型。

## 发现与修复

新只读 HTTP API 注册的前缀带尾斜杠，实际子路径全部返回 404。DSH 按 pathname === prefix 或 pathname.startsWith(prefix + '/') 匹配，因此注册必须使用 `/preset-enhance/api/v1`，不能再追加 `/`。已修复，增加采用宿主匹配规则的路由回归测试。原先单测直接调用 handler，未覆盖路由分发，所以未发现此问题。

## 真实宿主验证

临时探针以沙盒插件安装，在宿主内创建专用 agent，使用实际 tools.execute、HTTP fetch、Cordis 插件作用域和 pluginManager，结果全部通过：

1. 实际 agent 对象可通过读取接口的身份校验。
2. preset_read 在真实工具运行时注册、执行、输出校验及序列化成功。
3. HTTP 无凭证返回 401。
4. 短时凭证可以读取；重新签发撤销旧凭证；POST 返回 405。
5. Cordis 提供者卸载撤销目录；重新注册同版本新内容成功；旧清理不会删除新注册。
6. 无手动绑定时，chatHistory 动态模板在真实 HTTP 预览中注入。
7. 解析期间卸载提供者会拒绝旧解析；下次预览不复用旧结果。
8. 模板目录 SSE 收到真实注册与卸载通知。
9. HTTP 列表和内容读取成功，拒绝跨会话参数及非法分页；状态不包含宏变量和最近请求。
10. agent 销毁后其 HTTP 凭证失效。
11. 通过插件管理器停用预设插件后，服务和 HTTP 路由撤销；重新启用后读取恢复，工具仅注册一次。

测试探针源码保留在沙盒 `fixtures/preset-api-probe`；最终脱敏结果在沙盒 `home/preset-api-probe-report.json`。探针已卸载，专用 agent 已销毁，本轮启动的服务已关闭。修复后的预设插件快照保留在 alpha 供人工验证。清理探针后再次启动冒烟通过。
