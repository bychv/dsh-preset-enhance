# 皮肤与正文正则验证

日期：2026-10-14。本次针对开启正文正则后助手气泡背景消失的问题。

## 环境与方法

- alpha 槽位 DSH 0.2.1-alpha.2，独立临时 profile，不修改日常配置。
- 从 npm 安装 dsh-preset-enhance 0.3.6-alpha.1（含正文包）及 @smalltailqwq/dsh-client-ui-skin-maid-atelier 0.1.7。
- Edge 无头浏览器访问真实宿主，使用虚构预设和本地假模型端点，无真实 API 调用。
- 发布版复现后，仅在浏览器中将正文包 runtime.mjs 的响应替换为本地构建产物验证修复；不是已发布包修复验证。

## 原因与修复

皮肤按固定层级选择 Markdown 外层并设置气泡。正文替换增加容器后，新的 Markdown 节点深了一层，未匹配皮肤选择器；整页背景图仍正常。

替换容器继承原正文节点的样式类，保持皮肤所需的外层位置。正文映射排除自身显示容器，避免流式更新将它误识别为源正文。样式由皮肤继续控制，不复制颜色或写入皮肤专属选择器。

## 结果

- 发布版开启正文正则后，气泡背景变透明、内边距变为 0、圆角变为 0，截图复现。
- 修复后浅色背景、14px 18px 内边距与气泡圆角均与原文一致。
- 切换深色主题后气泡跟随变化；关闭正则恢复原正文，样式与替换显示一致。
- 正文替换生效，Markdown 加粗保持，HTML 字符串仍显示为文本；无页面脚本错误。
- npm run build 通过；正文规则、运行时和生命周期相关 12 项测试通过，包含自身容器排除、更新时复用及关闭恢复。

浏览器截图和报告保留在本机忽略目录 .test-data/skin-regex，不随仓库或 npm 包发布。本次未重跑完整 GenUI 兼容矩阵，也未验证其他皮肤。
