基线：next-ver 当前工作树；主包与新显示包本地版本字段为 0.3.5-alpha.1（本次未发布）。宿主为 alpha 槽位 npm DSH 0.2.1-alpha.2。

- `npm run build`：两个 TypeScript 项目成功，生成两个包的宿主入口和共享 Worker 模块。
- `npm run typecheck`：通过。
- `npm test`：557 项全部通过。

## 实际 alpha.2 宿主

两个目录按快照分别安装，核对 runtime、executor、Worker 和客户端入口与工作树相同。使用临时端口 3196、独立预设 state.json 和虚构会话；日常 3182 服务保持运行，共享预设状态的哈希未改变。

编辑器在实际 Web 服务加载，检查附加功能切换、Worker 试运行、自动保存、刷新恢复、浅色/深色及 420px 窄屏布局。没有浏览器异常，窄屏无水平溢出。

会话通过宿主公开接口创建和发送，使用本地 Chat SSE 假端点。临时测试插件固定本地地址并阻断外部模型请求；完成的端到端验证未使用真实模型。请求到达假端点，页面中的助手正文在流式结束前出现替换结果；原始 ChatSnapshot 仍保留未替换文本。

实际确认：Markdown 粗体仍显示，HTML 被转义而无 script 节点；思考块不被替换；保存正文开关后，现有页面通过 SSE 恢复原文或重新应用；运行时清理恢复原文并可重新接入。

试验中修复了两处仅计算测试无法发现的问题：宿主 slot 的 display:contents 包装层，以及 React 的 commit 不保证在下一帧完成。后者由 layout-effect 提交确认修复，并纳入自动回归。

## GenUI 共存

共装 npm `@changfenhuang/dsh-genui@0.11.1`，与本机参考源码版本一致。其 peerDependencies 尚未声明支持 DSH 0.2.1-alpha.2，因此仅为该版本组合授予沙盒精确豁免；不修改 GenUI 源码与发布包。客户端实际使用 DOM 通道。

本地假端点连续返回普通正文和混合回复（普通代码块、dsh-ui 文字/输入组件、svg）；确认正则继续替换包含组件的整段 Markdown，组件文本也来自替换结果，GenUI 与 SVG 能正常显示。保存显示开关后重新接管，关闭或清理显示运行时后宿主原有组件仍可见；刷新历史后正文替换与组件均恢复，没有浏览器异常。组件出现不会触发整条回复回退。显示副本提供 data-streaming，按实际流式状态更新。

不承诺跨显示开关保存第三方表单状态，也未验证改变围栏数量、顺序和语言的规则。测试会话使用公开接口归档；测试后移除新增 GenUI 安装并撤销临时版本豁免，临时端口服务关闭。
