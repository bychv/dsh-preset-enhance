# 跨会话工作台与预填充验证

日期：2026-10-16。宿主为 alpha 槽位 npm DSH 0.2.1-alpha.4；使用独立临时 profile 和虚构预设。

## 跨会话卡顿

Edge 中从三个不同会话的顶栏进入预设页，再打开侧栏工作台，发布版 0.3.6-alpha.2 可复现页面无法载入，浏览器内普通 API 请求超时。缓存 iframe 各保留两条 SSE，耗尽 HTTP/1.1 同源连接池；CSS 隐藏不会触发 iframe 的 pagehide。

本地修复由宿主通知 iframe 的活动状态，隐藏时关闭请求快照与模板/显示状态订阅，返回时重连。保留原文档和滚动，不伪造 pagehide。还覆盖浏览器标签页隐藏、完整导航、页面尚未载入即被隐藏，以及迟到通知。

修复构建通过隔离 profile 的本地链接安装；Edge 仅对客户端入口增加测试服务引用以驱动会话，其余工作台和宿主逻辑使用实际安装版本。验证结果：

- 三个会话顶栏预设页、侧栏工作台均可载入，普通 API 返回 200。
- 隐藏缓存页的 SSE 已关闭，只有当前工作台保持订阅。
- 返回工作台保持同一文档和原滚动位置。
- 点击“新建会话”后模式按钮可见、可点击并能打开菜单。
- 无页面脚本错误。

## 思考与正文预填充

预设编辑区“Assistant 预填充”新增“预填充到思考”开关，默认开启；以 preset.dsh_prefill_target 保存，关闭为 content，开启为 reasoning，不保存为全局接口配置。旧预设缺失该字段时默认思考。普通文本和带标签的末条 assistant 都遵循选择，工具续轮继承同一预设的目标。

本地双协议假端点配合真实宿主验证了 think、thinking 及普通正文前缀，包含工具转换开启与关闭的情况。请求含 prefix:true，文本到达所选字段。浏览器确认开关位于预设编辑区、旧预设默认开启、切换自动保存，后续请求按正文发送。单文件分享的往返、非法值拒绝、历史思考保留、工具续轮与模型关闭思考时回退正文由回归测试覆盖。Raw 预览使用同一预设目标构造请求。

另外在用户授权下向官方 Beta 发出 4 次 deepseek-flash 短请求，每次上限 192 token，使用虚构算术问题，不执行工具：

- 旧版 thinking 包装位于正文，模型将其作为正文字面内容继续。
- 修复后 thinking、原有 think 包装均转为 reasoning_content，均继续指定的思考片段并给出答案。
- 普通正文前缀的直接请求正常续写，本次没有复现其失效。

这 4 次请求验证通道语义与标签转换，不代表对任意预设的生成质量作保证；后续显式目标开关复用相同的 wire 字段，由假端点和回归测试验证，没有追加真实调用。密钥、完整响应及截图不随仓库或发布包保存。
