# 包内文件整理与正文开关联动验证

日期：2026-10-13。分支：next-ver。宿主：alpha 槽位 npm DSH 0.2.1-alpha.2，源码核对同版本标签；不是日常 DSH。

## 范围

正文包浏览器源码、执行器及共享 Worker 已迁移为 TypeScript，主包正则编辑模块与可用性通知也由构建生成。其他旧工作台模块仍逐步迁移。主包、正文包和组合包保持既有划分。

类型检查与构建通过；全部 565 项本地回归通过，覆盖规则、保存、执行器、生命周期和通知连接。迁移保持已有资源 URL 和浏览器 ModuleLoader 加载方式。三包打包清单需包含各自运行产物，不含样本、源码临时目录或私密数据。

## 真实宿主

使用独立 `preset-regex-lifecycle` profile 和临时 3196 端口验证。顶层仅声明组合包，由两个已安装的本地构建快照提供运行包；未用未发布的子包请求 npm。状态文件、模型连接与提示词均为隔离的虚构夹具，使用本地协议服务器；没有请求真实模型 API。

- 主包工作台与 SPreset 正则编辑、真实浏览器 Worker 试运行、自动保存及刷新正常。
- 工作台、SPreset 和对话同时打开，正文包状态正确同步；已有模板通知与正文状态共享连接。
- 通过宿主 pluginManager 的公开 `setPluginEnabled` 操作停用、重新启用正文条目；这与原生页面开关使用同一操作。
- 停用后显示副本清理、正文恢复，两处总开关关闭且不可操作；提示词开关保留。
- 停用期间自动保存规则、刷新编辑器，保存的正文开关偏好不变；重新启用后恢复开关，历史正文重新替换，规则修改生效。
- 原生插件管理器的组合包详情页显示两个运行条目，可分别控制。单独选择独立入口仍有各自卡片，不能同时选择组合入口重复装配。
- 页面无未捕获异常。临时宿主在验证结束后关闭。

真实验证发现并修复：新增独立 SSE 导致浏览器同源长连接饱和，改为内置编辑器复用模板通知；Cordis 提供的服务在 fiber 完成激活前不可读取，补充可选注入作用域的激活通知。

## 验证边界

流式及 mixed fence 的原文保留、超时、迟到结果与清理由既有运行时回归覆盖。GenUI 的真实共装证据仍为 [2026-10-12 记录](2026-10-12-DISPLAY_REGEX.md)；本次未重新安装 GenUI 做完整共装矩阵，没有新增围栏转换或组件渲染能力。

页面隐藏与返回的重新订阅由生命周期回归覆盖；不把它写成已经做过全部浏览器 BFCache 行为的人工验证。未发布三个包。

实现与契约见[包地图](../../packages/README.md)、[正文正则](../api/DISPLAY_REGEX.md)和[生命周期回归](../../tests/display-lifecycle.test.mjs)。

## 原主包入口平滑升级

后续改为主包直接携带正文依赖；上述独立组合入口验证仍保留为历史依据。新增验证使用 alpha 的独立 `preset-upgrade-test` profile，仅选择原 `dsh-preset-enhance` 入口。先安装改动前的本地主包 tarball，保存虚构预设、当前选择、会话绑定与预填充配置，再用 pnpm 离线升级到新主包 tarball。因为版本尚未发布，正文依赖通过测试 profile 的本地 tarball override 提供；没有将本地路径写入发布 manifest。

验证通过：

- profile 顶层依赖及选中的 bundle 仍只有原主包，正文包由依赖自动安装。
- 升级重启后，原保存文件哈希不变，所选预设一致；没有迁移或重置预设、绑定与设置。
- 原主包的原生插件详情页显示两个运行条目，正文包仅加载一份。
- 新增正文替换默认关闭；插件管理器停用正文条目后重启，停用状态保留且预设文件仍不变。
- 构建与类型检查通过，针对显示配置、生命周期及编辑器的 32 项回归通过；主包和正文 tarball 清单不含样本或临时数据。

没有请求模型 API，也未向 npm 发布。临时宿主已关闭，测试 profile 已清理。验证覆盖本地 tarball 升级及真实宿主加载；正式 registry 的下载安装仍须在子包发布后核对。
