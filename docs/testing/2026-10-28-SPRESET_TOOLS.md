# 2026-10-28 实验性 SPreset 工具验证

验证 next-ver 的实验实现，宿主为 alpha 槽位 npm DSH 0.2.2-alpha.2。独立测试状态、localhost 假模型、虚构工具，不使用真实预设或模型凭据。临时服务结束后关闭。

## 执行范围

- npm run build：主包、正文包与浏览器 TypeScript 检查及产物生成通过。
- npm test：603 项通过，其中实验工具相关 11 项，覆盖引擎隔离、中断/取消、纯 Promise、绑定与顺序表、同名会话隔离、脚本变更、开关及生命周期、格式化、暂存刷新、失败恢复与错误结束。
- 编辑器文案调整后，SPreset 编辑器及资源库 27 项回归通过。
- npm run pack:check：打包检查通过；引擎作为 npm 运行依赖安装，sample 与 .test-data 未进入发布包。
- 真实 DSH 使用已安装插件，经官方 sessionController 创建会话及发送，假接口共接收 12 个请求（包含辅助请求），外部模型调用为 0。

## 真实宿主结果

1. 启用后，内嵌工具进入实际出站工具 schema；action 通过 DSH 执行，结果进入同轮续写请求。
2. 开启调用消费后，结果直接成为宿主持久化的 assistant 正文，没有工具调用/结果历史，也没有额外工具续轮。
3. formatter 失败时恢复调用，由 DSH 执行并带结果续轮。
4. 关闭实验开关后，下次请求不再带该工具。
5. 导入带启用标记的虚构预设，保存状态恢复关闭。
6. 非流式预填充请求确实携带 prefix；已有兼容层恢复的 DSML 调用可被消费为正文，并由宿主保存。

实际宿主验证发现结束事件不能显式携带 undefined 字段，否则无损 JSON 记录会拒绝持久化。已改为移除不适用的 replayState，并增加标准事件 JSON 往返回归。改写工具块后不保留指向原块的 replay 元数据。
