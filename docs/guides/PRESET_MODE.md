# 预设模式

先在预设工作台导入并选择预设，再在新建对话时选择「预设模式」。模型使用该预设组织的提示词，工具沿用宿主标准模式的组成。

## 模式说明

### 提示词从哪里来

预设模式按酒馆预设的顺序表、聊天记录占位、深度注入和变量宏生成请求，不额外加入 DSH 默认身份提示与运行环境快照。角色、回复风格和工作方式由预设决定；导入预设本身不会执行其中的任意脚本。

新会话从首轮自动启用当前默认预设。在当前会话的工作台切换预设后，下一次请求使用新选择；已经发送的消息和旧请求快照不会随之改写。

### 保留哪些工具

工具来自宿主当前标准模式的组成，不维护一份固定工具清单。可在工作台设置模式默认工具策略，或为当前会话单独覆盖，也可以按组启停。提示词说明不能代替工具权限；工具仍受宿主权限和插件工具策略约束。

### 什么时候选

适合使用已有酒馆预设、定制回复格式，或调试提示词顺序和前缀续写。若希望沿用标准、PTC 等模式的原有系统提示，同时叠加预设，可以在这些模式启用预设注入，并保留工作台置顶的「DSH 系统提示词」开关，无需改用专用预设模式。

### 预填充与显示替换

预填充要求支持前缀续写的 Chat Completions 连接，可使用「DeepSeek-预设增强」并开启预填充自动兼容。预设编辑区选择前缀写入思考还是正文，默认思考；Messages 连接不支持该能力。工具调用兼容处理需按接口配置开启。

正文正则属于可选显示包，只改变看到的正文，不改变会话原文、后续模型上下文或宿主导出。提示词正则则处理发送给模型的副本，两者分别开启。

## 如何使用

### 使用已有预设开始对话

1. 从侧边栏打开「预设工作台」，导入酒馆 JSON 或单文件分享预设，确认当前选择。
2. 新建对话，选择「预设模式」，检查模型与连接，再发送消息。
3. 从会话打开工作台，用消息预览和 Raw 检查实际出站请求。

示例任务：

> 按照当前设定，写一段雨后书店的开场，让故事停在访客推门进入时。

预期产出：遵循预设角色与风格的回复。实际表现取决于预设内容和所选模型；仅切换模式不会自动生成角色设定。

### 使用自定义工作方式处理项目

在预设中写入工作要求，例如先核对资料、回答附来源；在工具面板保留读取与检索所需工具，然后发送：

> 阅读项目中的 Markdown 文档，整理已完成的功能和待办项，为每项附上来源文件。不要修改文件。

预期产出：按预设格式整理的项目说明。若不希望允许写入，应同时通过工具策略或宿主权限限制，而不是只依赖这句提示词。

### 调试前缀续写

在预设编辑区填写简短的 Assistant 预填充，例如「结论：」，将目标切换为正文，选择支持续写的 Chat 连接并开启自动兼容后发送：

> 用一句话说明这个虚构项目的用途：它把每日阅读笔记整理成按主题分类的索引。

预期产出：前缀参与正文续写。发送后查看「实际请求」来源的 Raw，核对末条 assistant 的 `prefix: true` 与对应 `content`；思考目标则核对 `reasoning_content`。不能仅凭草稿标记判断接口已收到前缀，模型展示也不一定重复回显已提交的前缀。

## 宿主展示范围

当前宿主允许第三方模式提供 `description`，用于模式选择器和设置卡片的简介。官方「模式说明 / 如何使用」弹窗只接受内置的 standard、ptc、minimal、cordis 模式，尚无第三方指南注册入口，因此本文不宣称已接入该弹窗。
