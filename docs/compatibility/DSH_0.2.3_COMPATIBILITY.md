# DSH 0.2.3 兼容

当前源码的主包、正文包和兼容入口均纳入 DSH 0.2.3-alpha.2 起的 0.2.3 系列。已发布的插件 0.3.7-rc.2 覆盖 DSH 0.2.1 和 0.2.2。沙盒验证使用 DSH 0.2.3-alpha.2 和 Node.js 24.22.3。新版宿主的 Node.js 要求见 [DSH 发布说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.3-alpha.2)。

DSH 从 0.2.3 起按来源保存系统提示词。一轮可能只追加变化的段落，也可能沿用之前的段落。插件按消息的段落元数据合并这些记录，处理段落撤销和整篇重建，再用有效正文核对本轮组装结果。替换或撤销的通知不会进入可编辑模板。旧宿主继续按整篇系统提示词核对，两个路径都核对本轮工具清单。

## 验证

- 在 0.2.3-alpha.2 的独立 Web profile 安装主包和正文包的本地 tarball，确认两个包实际加载，工作台 API、正文包状态及上下文附件可用。
- 在 0.2.3-alpha.2 和 0.2.2-rc.5 上，用回环假端点分别验证系统提示词分段覆盖、禁用、整篇覆盖、宿主 complete 规则、草稿预览以及同轮工具调用后续写。
- 在 0.2.3-alpha.2 上核对动态预填充的实际请求。首请求包含生成前缀和 `prefix: true`，工具续轮包含工具结果，生成器只运行一次。
- 本地构建和 648 项回归通过。增量提示词测试覆盖部分更新、撤销、重建及正文或工具不匹配。
