# 按模式配置默认预设与新对话选择

Status: proposed

## 问题

当前工作台记住全局选中的预设，自动注入的模式也从同一份全局预设取默认值。不同模式需要各自的默认预设。新对话里也应能在右侧栏浏览预设内容，确认本次会话要用哪一份。

## 方案

### 模式默认

- 在工作台现有的自动注入设置附近加入「模式默认预设」。复用宿主模式列表 `agentPresets.list()` 和现有的 `agentModeRows`，包括其他插件注册的模式。下拉项显示模式名，按稳定的模式 ID 存储。模式暂时停用或热重载时保留已存映射，重新出现时恢复。
- 在全局状态增加从模式 ID 到预设 ID 的映射，每个模式可单独保存或选「跟随全局」。旧状态按空映射读取。删除预设时同步清掉指向它的模式默认项，回到当前全局默认的回退规则。分享文件只携带预设本身的配置，模式关联随本机状态保存。
- 统一请求、工作台、只读查询和正文正则的预设选择。优先使用显式会话绑定（也尊重显式关闭），无绑定时使用当前模式默认，再回退到现有全局默认。模式默认决定用哪一份，已有「新会话自动启用」规则决定是否自动注入。用户在新对话中明确选择预设属于该会话的主动启用。

### 新对话右侧栏

- 使用 DSH 公开的右栏标签注册接口，在右侧栏添加「预设」页，放入右栏的添加页入口。面板顶部显示输入框当前模式和生效预设，下方放可搜索的预设选择列表与只读预览。通过「使用此预设」应用到本会话，通过「跟随默认」回到当前模式的默认规则。编辑入口跳到现有工作台。
- 预览显示选中预设实际使用的提示词顺序、角色、启停、历史标记、深度注入和助手前缀。点击条目展开正文。列表只请求名称等摘要，选中后再加载对应详情。只读预览从保存的预设读取，动态条目标出来源。实际请求预览沿用工作台的解析与授权流程。
- 订阅输入框的模式选择。切换模式时，继承设置的草稿随新模式更新，显式选定的预设保留并标为「本会话」。浏览候选、预览和关闭侧栏都不写默认值。
- 有宿主空白会话 ID 时直接使用会话绑定。0.2.3-alpha.2 的原生右栏需要会话作用域，应先验证新对话入口能否取得受保留的空白会话。宿主还未分配 ID 时，通过公开的输入区入口打开右侧选择面板，按当前草稿标识暂存选择。通过宿主创建流程拿到该草稿的会话 ID，在提交首条消息前等待绑定成功。若宿主提供创建时携带扩展数据的接口，优先一次提交。绑定失败时留住草稿并允许重试。

## 考虑过的替代方案

把快速选择接到工作台的全局预设切换会影响其他仍然继承全局默认的对话。右栏选择应沿用会话绑定，设置模式默认应由独立动作保存。

## 验收与风险

- 全局预设为 A，两个模式分别配置 B、C。新对话切换模式立即刷新默认项和预览，重启后配置可恢复。新增插件模式可配置，删除 B 后对应模式恢复继承全局。
- 新对话右栏可搜索、选中、展开预览并应用。手选 D 的会话首条模型请求使用 D。两个窗口或两个草稿同时选不同预设，首条消息只使用各自绑定。取消选择、刷新和发送重试不会把选择应用到其他会话。
- 未启用自动注入的模式可以预览和手动使用预设。已有会话的显式绑定和禁用状态得到保留。工作台、只读查询及正文正则能识别同一个有效预设。
- 用沙盒验证右栏开关、窄屏、模式切换和无 ID 到首条消息的时序。兼容范围内若缺少原生右栏能力，通过可用的宿主入口保留同一选择流程。点击预览保持无副作用，同时验证旧草稿请求不会覆盖当前预览。
