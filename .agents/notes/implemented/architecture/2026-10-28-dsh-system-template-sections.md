# DSH 系统模板分段编辑与本轮组装结果复用

Status: implemented

## 问题与依据

2026-10-28 在 next-ver 核对沙盒 DSH `0.2.2-alpha.2`（`f3803c96974ad4a94195fb97e5c637e9c2a3afe3`）。宿主每个 step 先准入工具，再收集作用域段落和变量、执行 waterfall 及 complete 规则；系统正文、独立运行环境上下文和工具 schemas 分别进入请求。

此前插件在 llm/stream 注入时重新组装，未携带宿主本轮 toolSet，可能让 SDK 与实际工具集合不一致。编辑则保存整篇正文，修改一处也会固定其他展开的段落；名称名单无法覆盖第三方动态内容。

## 实施决定

### 复用已接受的组装

[工具准备桥接](../../../../src/lib/tool-restrictions.mts)在原 assemble 完成后调用观察回调，读取宿主最终返回结果。沿用原有方法包装和释放机制，没有新增第二套组装拦截。不能仅缓存 waterfall 入口对象：它仍可能被其他监听器修改，complete 规则也在事件返回后才执行。

[本轮关联](../../../../src/lib/dsh-assembly.mts)只接收真实 live Agent、对应 scope 和请求信号的组装；独立预览以内部 Symbol 排除。分离保存 sections、contexts、variables、tools 数据，不持有或释放宿主 toolSet、scope lease。

通过官方 agent/pre-step、agent/request 确认 turn/step 和发送阶段。实际请求再核对 Agent 身份、模式、信号、provider/model、原始系统正文与 schemas；匹配才复用。请求中的推理强度可能已经展开为适配器默认值，因此不以其与原选择的字面差异判定串轮。

工具续轮替换记录，传输重试使用当前 step 的记录。step/turn 结束、模式切换和停用清理；取消及关联不符时拒绝使用。旧异步准备失败只清理自己仍持有的记录，避免删除较新 step。未建立关联的手工、旧式嵌入调用仍独立组装，不把不明来源的会话缓存当作本轮依据。

### 分段继承与持久化

新字段 `dsh_system_prompt_sections` 按预设、模式 ID、宿主段落名称保存局部覆盖；结构及限制以[格式文档](../../../../PRESET_FORMAT.md)和[公开说明](../../../../docs/api/DSH_SYSTEM_TEMPLATE.md)为准。

- 没有覆盖时跟随默认，不保存宿主正文快照；所有段落均可动态更新，不依赖名称名单。
- custom 保存模板并解析宏，disabled 排除该段落；顺序沿用宿主。
- 来源消失时覆盖休眠且保留数据，来源恢复后再应用。自定义文本主动引用缺失宏仍明确报错。
- 旧整篇 `dsh_system_prompt_templates` 优先使用，包括空字符串；不自动拆解。用户确认切换为分段编辑后才移除本模式旧正文。
- 单段恢复只删除该项；整模式恢复删除本模式的整篇和分段覆盖，其他模式保留。

[共享选择逻辑](../../../../src/lib/dsh-template-source.mts)同时用于请求编译和客户端预览。按段落分别展开后排除空结果再连接，避免空动态段落产生额外空行。保留原有宏值按字面插入、旧 URI 宏及原会话不被修改的行为。

### 编辑器与性能

[客户端 TypeScript 模块](../../../../src/client/dsh-template-editor.ts)位于原 DSH 条目内部，提供折叠段落、三种状态、单段恢复、整篇切换、完整组装预览和只读上下文。折叠状态保存到浏览器；输入修改沿用当前预设草稿和全局自动保存。

完整预览展开时才计算，折叠时只标记待更新。不新增持续轮询；工作台进入、聚焦及模式状态刷新时读取默认数据，发送仍使用本轮动态值。宿主注册变化不等同于动态函数取值变化，不能用注册通知构造跨轮值缓存。

草稿预览独立组装，不覆盖本轮；最近实际请求/Raw 使用发送快照。局部预览中的其他酒馆变量需要使用下方草稿解析结合会话调试。新增分段面板通过受保护的动态 import 加载；资源缺失时仅禁用该面板并提示重启，其他预设配置仍可读取。CLI 安装快照不会自动证明旧进程已加载新静态路由，验证时需要检查实际 HTTP 依赖图。专用预设模式、总开关及已有运行环境移除范围没有调整，工具 schemas 与权限仍由宿主管理。

## 其他选择

- 扩充动态段落名称名单不能覆盖第三方及新增内容，不采用。
- 只给整篇正文拼接段落宏仍固定段落集合，不能自动继承新增段落；保留为用户主动选择的整篇模式。
- 从旧正文猜测段落边界无法可靠恢复编辑意图，不自动迁移。
- 只按 sessionId 缓存最近结果不能区分预览、续轮和重试，不采用。

## 影响与验证

构建和 611 项自动测试通过；alpha 真实宿主本地假接口验证了每 step 一次组装、原生工具续轮、分段覆盖、缺失来源、旧整篇优先级及 complete 规则。正式记录见[系统模板验证](../../../../docs/testing/2026-10-28-SYSTEM_TEMPLATE_SECTIONS.md)。没有外部模型调用。

浏览器自动化初始化失败，未做实际截图检查；UI 用模拟 DOM 验证。本次没有完整重测插件管理器热重载，也没有重新启动旧宿主版本；不将源码判断或自动夹具写成这些场景已人工通过。
