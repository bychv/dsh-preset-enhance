# 分享文件预填充配置恢复

Status: implemented

## 原因与修复

旧导入只保存 sharePackage 附件，没有应用其中的 prefill；工作台继续回填旧全局值，随后可能按旧正文提取开关补模板。现在 [导入事务](../../../../src/index.mts)在验证分享文件后同时恢复六项预填充字段，再按最终开关补入缺失模板，失败整体回滚。

缺失或 null 的 prefill、普通 ST JSON 不重置本机接口配置。显式 false、空续轮文本保留，旧包缺失 extractOutput 按关闭处理。接口配置仍属全局，导入提示明确会影响其他会话；不切换连接、模型或工具权限。Messages 下保留设置，仅暂时不可用。

[共享联动函数](../../../../src/lib/preset-package.mts)统一导入、再次应用和保存接口设置的模板补入；已有条目保留用户正文和启停，不重复添加，关闭不删除条目。工作台导入及再次应用先等待旧全局写入，再恢复配置并重新读取，不再二次保存导入草稿。

## 附带字段核查与验证

分享包回归覆盖未知包装字段、工具版本/分组与引用、普通 JSON、错误原子性、开关关闭/空值、全新 Store 读取、再次编辑导出；补充系统模板空值、max_tokens=0、stream=false、正则禁用项、SPreset、动态关联配置等往返断言。工具仍须显式导入，不自动授权。未发现这些字段需要新增迁移。

工作台回归验证导入等待旧保存、读取恢复后的接口控件且不会额外保存旧草稿；既有请求回归验证持久化设置的消费路径。全量 566 项回归及构建通过。本次没有做真实 API 或完整沙盒导入端到端测试，不以字段往返代替所有外部模板提供者的运行验证。

契约见[分享格式](../../../../PRESET_FORMAT.md)，测试见[分享包](../../../../tests/preset-package.test.mjs)与[工作台设置](../../../../tests/editor-settings.test.mjs)。
