# SPreset 中栏提示词条目的快捷操作

Status: implemented

## 问题与来源

用户在 2026-10-12 提供参考截图，要求中栏条目提供三段角色切换、电源启停及六项更多操作，并随后要求执行。实施基线为 next-ver 分支 `b0c2406`：角色切换只在右侧检视器，条目重复提供滑块与电源，更多菜单缺少真正删除等操作。

## 决定

- 中栏常驻 system / user / assistant 三段图标按钮、电源按钮及更多菜单；点击条目查看检视器。按钮提供中文名称、悬浮说明和当前状态。导入的 `model` 显示为助手，展示不改写原值；复制到仅支持标准三种角色的资源库时使用 `assistant`。
- 角色更新提示词本体并同步中栏、左栏角色展示与检视器，所有顺序组共享这一角色。电源只修改当前顺序组的 `enabled`，停用仍属于已使用。
- 更多菜单依次提供上移、下移、移到未使用、复制为模板、创建副本、删除。首尾移动操作禁用，原拖动排序保持实时让位与 Esc 取消。
- 移到未使用只移除当前顺序组引用，保留本体及其他组的引用，切回左栏未使用分区。创建副本采用新 identifier 和深拷贝，插在原条目后，继承注入配置、未知字段和当前启停状态。复制为模板复用独立资源库保存接口。
- 删除确认说明名称和引用的顺序组数量；确认后移除本体、各顺序组引用、本预设对应的 `templateBindings` 和 `autoTemplateDisabled` 数据，清理失效选择。资源库模板与外部提供者定义不受影响；保存时宿主清理已不存在条目的编辑器锁，其他条目及预设的锁保留。
- marker（含 `chatHistory`）角色只读，可停用、排序、移到未使用，不能直接复制或删除。外部手动关联条目沿用角色只读限制，复制前须通过既有面板解除关联；删除普通关联条目允许清理本地关联而不操作提供者。正文锁定时复制和删除禁用，角色和启停遵循原正文锁的范围仍可修改。这些保护也在动作函数中检查，不能通过其他复制入口绕过。
- 菜单放在独立浮层，位置限制在视口内，支持方向键、Home/End、Tab、Esc、点击外部关闭及返回触发按钮焦点。按钮键盘事件不选中行，指针事件不触发拖动。异步菜单失败显示错误。条目采用紧凑控件、长标题省略，支持明暗主题和窄屏。

## 考虑过的替代方案

只保留检视器角色下拉框不满足条目快捷操作需求；保留滑块与电源会重复表达同一状态。实现复用已有预设、顺序组、资源库和保存路径，没有新增平行状态或接口。

对 marker / 动态关联条目直接换 identifier 复制会丢失其身份或解析语义，因此要求通过现有解除关联流程处理，再复制普通条目。正文锁定条目先解锁再复制，避免复制出来的正文绕过编辑器锁。

## 影响与验证

- `npm run build` 通过类型检查，更新根目录宿主产物。
- `node --test tests/spreset-editor-ui.test.mjs tests/s-preset-library.test.mjs`：27 项通过，覆盖角色及启停同步、保存重开、多组删除与取消、元数据清理、独立副本、模板保存失败、特殊条目保护、菜单键盘与拖动，以及真实保存路由的锁表清理。
- 本地 Edge 使用虚构预设验证页面交互、保存后刷新、菜单焦点与下缘定位，检查明暗主题及 420px 窄屏无横向溢出。此验证使用模拟 API；保存路由另由宿主集成测试覆盖，未安装或启动 DSH 沙盒、未调用模型接口。
- 使用说明已同步；此记录不代表发布或安装完成。
