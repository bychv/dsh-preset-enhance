# 按模式配置默认预设与新对话选择

Status: implemented

## 决定

工作台在「新会话自动启用预设注入」中读取宿主模式列表，按模式 ID 保存默认预设。旧状态视为无模式覆盖，已停用的模式保留映射，删除预设时清理其引用。模式关联属于本机全局状态，分享文件继续携带单份预设的数据。

请求先检查会话绑定，再检查该模式的新会话自动启用设置。符合自动启用条件时，先取模式默认，再取全局默认，首轮编译时记住使用的预设。右栏手动应用直接绑定并启用当前会话。恢复跟随默认时清除绑定，由后续请求重新按模式和自动启用规则决定。右栏查看和预览只读保存内容，动态模板沿用实际请求中的解析流程。

右栏选择器注册在 DSH 的会话作用域，也可从输入框旁的「预设」打开。沙盒中的空白新对话已有独立会话 ID，应用时可直接保存绑定，保存期间暂缓该会话发送。没有有效会话 ID 时仍可预览，应用需要等会话就绪。切换模式时，右栏读取输入框的最新选择；手动绑定继续随原会话保留。选择器在浏览器标签恢复可见时刷新，避免从输入框切回右栏时因焦点刷新吞掉应用点击。

让右栏复用工作台的全局预设切换会影响其他继承全局默认的会话，因此采用独立的会话操作。

## 验证

- `npm run verify` 通过 650 项测试，包含插件提供的模式、每模式默认值持久化、首轮选择、手动绑定、清除绑定和删除预设后的回退。
- 在 DSH 0.2.3-alpha.2 的隔离 Web 配置中，用 Edge 验证原生右栏、搜索和展开正文、切换模式、恢复默认。实际 DSH 首条出站请求由本地虚构接口捕获，确认携带手动选择的预设。
- 核对了 DSH 0.2.1-alpha.1 和 0.2.1-rc.5 的右栏插槽和输入框阻塞接点。浏览器联动的验证范围为上述 0.2.3-alpha.2。
