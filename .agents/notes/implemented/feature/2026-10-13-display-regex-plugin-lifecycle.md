# 正文正则开关与宿主插件管理器联动

Status: implemented

## 问题与最终行为

正文执行由可选分包提供。用户要求正文开关与 DSH 插件管理器联动，分包未启用时默认禁用，避免开关显示开启而没有执行能力。

主包通过公开 `presetDisplayRegex` 能力读取当前实例的就绪状态，正文包完成资源检查后提供能力、退出时撤回就绪。有效开关等于能力可用且预设保存的开关开启。未安装、停用、加载失败、状态未确认及通知断线时，工作台和 SPreset 显示关闭并禁用总开关。规则可继续编辑保存，提示词通道独立。

暂时不可用不修改预设偏好，避免自动保存污染规则和分享文件。恢复就绪后使用保存的偏好，原本关闭的预设不会自动开启。服务、API 与前端状态见[公开契约](../../../../docs/api/DISPLAY_REGEX.md)。

## 真实宿主发现的两个边界

Cordis 的 `ctx.get()` 默认只返回已完成激活的服务。正文包 apply 内发出的就绪事件早于整个 fiber 的激活，单凭事件会将重新启用判为关闭。主包通过可选 `ctx.inject()` 作用域补充完成激活及退出通知，保持主包无需正文包也可运行；不监听宿主私有管理器内部结构。

在同时打开工作台、SPreset 和对话时，独立新增 SSE 曾占满同源 HTTP 长连接名额，让 Worker 资源排队超时。内置编辑器现复用模板通知连接的 `display` 字段，同一页面的模板和正文状态订阅共享连接且独立释放；仅正文状态改变不额外刷新模板目录。GET 仅用于初始读取，迟到结果不能覆盖已收到的事件。页面隐藏释放连接、返回时重新确认状态。

## 清理与验证

正文包沿用宿主客户端生命周期的清理：退出时恢复原文、终止 Worker、撤销挂载和订阅；新实例不采纳旧结果。服务端配置 SSE 同步有效状态及保存偏好，不保存临时禁用值。实现见[配置服务](../../../../src/lib/display-config.mts)、[通知模块](../../../../src/client/display-availability.ts)与[正文入口](../../../../packages/display-regex/src/index.mts)。

[自动回归](../../../../tests/display-lifecycle.test.mjs)覆盖激活、退出、实例替换、偏好保留、迟到 GET、共享连接和页面返回。[真实宿主验证](../../../../docs/testing/2026-10-13-PACKAGE_LIFECYCLE.md)覆盖原生管理操作、两处编辑器同步、停用期间自动保存和重新挂载。源码整理遵循[TypeScript 约定](../architecture/2026-10-12-package-layout-typescript.md)。未运行真实模型 API。
