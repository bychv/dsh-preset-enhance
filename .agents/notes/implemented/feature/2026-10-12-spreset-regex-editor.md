# SPreset 附加功能的正则编辑

Status: implemented

## 布局与归属

用户要求附加功能只做正则，并沿用现有顶部切换。实现采用左侧规则筛选和列表、右侧表达式/替换/执行位置/执行条件卡片；窄屏在规则列表与详情之间切换。不显示其他尚未实现的附加功能占位面板，不堆积界面解释。

规则共用预设 `extensions.regex_scripts`，支持新增、复制、删除、排序、启停、捕获组、清理匹配内容、查找式宏与深度。两个通道独立开关，正文执行需要可选显示子包。SPreset RegexBinding 和其他未知字段原样保留，不自动合并执行。

## 保存与试运行

编辑标记同一预设草稿，沿用保存、导出和单文件分享。顶部自动保存同步工作台的全局偏好；写入串行化并以草稿版本区分保存过程中继续输入，避免误报已保存。切换预设取消旧计时器，不将旧草稿写到新预设。

试运行默认折叠，手动触发 Worker；支持当前/全部规则、角色、通道和深度。输入规则时不执行正则，切换规则或修改配置会取消旧任务，防止把迟到结果显示在新条目中。

## 原切换问题

`.columns { display:grid }` 覆盖了原生 hidden 的显示规则，切换未真正隐藏提示词列。现使用 `[hidden] { display:none!important }`，附加功能同步展示，不依赖旧判定接口成功。
