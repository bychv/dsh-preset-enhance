# Raw 预览的完整工具信息与简洁 JSON 界面

Status: implemented

## 实现

原始请求捕获本来就保留 tools 与消息中的工具历史，本次不从当前工具面板补历史，也不改动传输数据。预览模块迁移至 [TypeScript 源码](../../../../src/client/request-preview.ts)，构建生成既有 web/request-preview.js URL，仍作为经典脚本加载。

Raw 改为紧凑 JSON 树，默认打开浅层消息及工具条目，摘要包含角色或工具名；长文本直接显示摘要并就地展开。提供展开一层、收起全部，每个分支按 50 项加载，初始自动展开最多 40 个分支。深层 schema 和长结果按需读取 DOM，复制仍使用捕获的完整字符串，保留大整数精度及原空白。

工具摘要报告原生 tools 数量、控制字段是否发送，并标注消息是否含 DSML 文本。仅有文本不能证明由桥接转换，tools 缺失也不能区分主动移除或原本未提供，因此不凭当前开关编造来源状态。工具调用 ID、参数及结果在原协议 JSON 中查看，Messages 和 Chat 均保留原形。快照超限或未捕获维持不可用状态。

## 验证

[面板回归](../../../../tests/request-preview-panel.test.mjs)覆盖分页、批量折叠、长文本、完整复制、协议工具结构、快照切换与数值精度；既有请求回归覆盖实际转换后 Raw。全量 566 项回归通过。真实 Edge 检查工具名称、长结果、展开/收起及 2000 项目录节点上限，无页面异常；使用独立页面加载实际脚本和样式，没有运行模型或重新安装沙盒。

说明见[请求预览](../../../../docs/guides/REQUEST_PREVIEW.md)。没有增加响应调试或转换前工具目录副本。
