# 外部动态预填充的模板与读取接口

Status: implemented

## 决定

复用 `dshDynamicPrefill` 的末尾助手消息注入。预设增强提供模板关联、宿主轮次识别、正文投影、取消与失败处理。外部插件负责选择模型、调用服务以及配置和保存凭据。当前插件已有思考/正文前缀目标，没有独立的「显示前缀」选项，摘要返回实际存在的设置。见[模板 API](../../../../docs/api/TEMPLATE_API.md#外部动态预填充)和[读取 API](../../../../docs/api/PRESET_READ_API.md#进程内动态预填充摘要)。

- 两个编辑器按选中的顺序表展示闲置条目。目录补齐内置及提供者声明的标记，加入前只作为候选。加入写入草稿，自动关联和冲突选择沿用已有机制。
- 从 DSH 的 turn/start、agent/request 和请求取消信号确认首个模型请求。步骤编号可能在不同轮次延续，所以记录每轮首个实际请求的 step。续轮沿用既有静态前缀及工具后配置。无法确认轮次、未启用预填充或非受支持连接时跳过。
- 外部生成器读取有界的近期纯文本。返回文本按字面插入，回退由提供者显式选择，冲突在外部调用前和最终编译时检查。模板和配置更新、取消、卸载及超时都有失效检查。跨进程写入在请求提交时复核依赖，当前进程写入可即时取消。
- 主包提供进程内复用键。外部插件负责结果缓存、容量和请求合并。传输重试沿用已准备的请求。草稿预览需本次授权，预览和发送使用独立的取消与复用范围。HTTP 读取接口未增加生成和聊天历史权限。

## 验证

- 端到端测试覆盖安全正文、字面宏、预览授权、稳定复用键、冲突、工具续轮、静态回退、协议跳过和绑定变化取消。候选与 SPreset 编辑器测试验证按选中顺序表加入、去重及加入前不修改草稿。
- DSH 0.2.2-rc.2 隔离槽位和本地假接口实测两次请求。首请求带生成前缀，工具续轮未再调用提供者。验证使用虚构数据和本地提供者。
