动态宏与段落
上下文文件随本条提示词一起发送的图片或文件（可选）

粘贴图片或拖拽文件到此处

支持常见图片（PNG / JPEG / WebP / GIF）与文档（PDF / TXT / JSON）；单文件 ≤ 8 MiB，总计 ≤ 24 MiB（最多 24 项）。图片请添加到「用户」条目。

标记变量覆盖（JSON）

可为 charDescription、scenario、worldInfoBefore 等占位标记填入内容（留空则跳过）；填写 dshDynamicPrefill 可作为末尾动态续写前缀。

助手预填充（续写前缀）

作为末尾 assistant 续写前缀发送，是否生效取决于模型与接口。

消息预览

仅用于本地试算预览，不会保存草稿或修改会话变量。

工具权限与策略

分组仅用于整理和批量开关：每个工具最多归属一个分组，批量操作会同步更新逐条规则。

请求参数

设为 0 时沿用接口默认上限；随当前预设保存。

新会话自动启用与默认预设

勾选的模式在新建会话时会自动启用预设注入（仅对新会话生效）；专用「预设模式」始终自动启用。

助手预填充接口（全局）

当前会话使用 Messages 接口，预填充设置暂不可用；切换至对话补全接口后可配置。

开启自动兼容后，末条为 assistant 的预设会自动走预填充续写（官方接口自动切至 Beta，非官方地址不变）；开启「强制按预填充发送」可跳过自动识别。启用 DSML 兼容会转换工具定义与调用；关闭时官方 Beta 仍移除原生工具字段，非官方接口按上方开关决定是否保留 tools 等字段。

启用「自动分离思考与正文」时会自动加入格式提示词，可在提示词列表中查看或编辑。

开启预填充自动兼容后，用于替换同一轮工具执行后的续写前缀；留空或变量为空时沿用原预设。

正则配置

提示词正则处理请求副本；正文正则处理聊天显示（需安装正文显示包），两者共用规则且不改写历史记录。
